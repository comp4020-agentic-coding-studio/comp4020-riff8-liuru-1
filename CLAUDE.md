# Your harness

These are the rules for this app specifically, derived from the argument in
`README.md`. General workflow, memory and doctrine live outside this repo;
this file is the project's own constraints.

## What this app is

A recreation of Paper Planes (`README.md`): write a message on one of six
colours of paper, fold it, throw it; catch someone else's, read it, stamp it
with a place you choose, throw it on. The 六如 wall it replaced is kept
read-only at `/archive`.

## Rules

- A person is the `visitor` cookie. Show and log only its derived handle
  (`handleFor` in `src/log.ts`), never the cookie. No accounts, no list of
  who's present, no counts of people.
- The six colours are equal paper. A colour never encodes authorship,
  popularity or permission, and there's no seventh.
- A plane's message, colour, author and origin stamp are immutable; stamps
  are append-only. Every permission check lives in `src/planes.ts` and
  reads the server's own record, never a flag the client sends.
- Only the current lease holder may stamp or release (`releasePlane`). Keep
  the check in the SQL `WHERE` clause so forged and stale requests fail alike.
- Every write is idempotent by request key. Don't add a write path without one.
- Log one JSON line per action, after it commits. Never log a message body,
  cookie, lease id, IP or raw payload.
- No likes, rankings, notifications or streaks. Live updates never replace
  an open draft or message.
- A place is a label from `src/web/regions.json`, never a location. Don't
  request geolocation.
- Message bodies: 1–240 code points, line endings normalised, otherwise
  stored exactly as sent. Always render as text.
- No moderation yet (README names it). Revisit before the sky is exposed
  somewhere a stranger could flood it.

## Enforced vs. judged

`spec/*.test.ts` is the enforced list: planes (`planes.test.ts`), catching,
leases and permissions (`catching.test.ts`), live delivery (`live.test.ts`),
the archive (`archive.test.ts`), and the two course-wide checks
(`invariants.test.ts`). Whether it looks and feels like Paper Planes is
judged by eye at 1440×900 and 390×844.

## Stack notes for future runs

Plain Node (`node:http`) plus `better-sqlite3` on the Fly volume at `/data`;
no build step. The browser loads `src/web/*` as-is and three.js from
`node_modules` through an import map. Live updates are SSE from an
in-memory listener set (`src/live.ts`), which assumes one machine. The land
mask is generated by `scripts/build-land.ts` and committed.
